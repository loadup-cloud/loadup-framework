This artifact replaces org.jobrunr:jobrunr:9.0.0 on the runtime classpath.
Modification: ProcessRecurringJobsTask reloads recurring definitions through
RecurringJobCacheInvalidator.refresh, invalidating changed/deleted cursors.
All other upstream classes and resources are copied without changes.
The Apache-2.0 licensed LoadUp helper is separately identified by its header.

The matching sources classifier contains all upstream sources, the patched
source and the helper. Source and reproducible build instructions are in
https://github.com/loadup-cloud/loadup-framework under
loadup-components/execution/loadup-components-jobrunr.
Build: mvnd clean package -pl :loadup-dependencies,:loadup-components-jobrunr -am
Do not place the original JobRunr core jar beside this replacement.
