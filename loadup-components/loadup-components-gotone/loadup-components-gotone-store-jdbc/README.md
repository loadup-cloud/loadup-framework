# Loadup Gotone Store JDBC

多渠道通知的可选 JDBC 持久化模块。

## 引入

```xml
<dependency>
    <groupId>io.github.loadup-cloud</groupId>
    <artifactId>loadup-components-gotone-store-jdbc</artifactId>
</dependency>
```

## 装配与配置

模块提供以下自动配置入口；实际启用条件和配置项以对应类及父模块 README 为准：

- `GotoneStoreJdbcAutoConfiguration`
