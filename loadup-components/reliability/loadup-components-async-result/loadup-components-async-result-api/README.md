# LoadUp Async Result API

业务仅依赖本模块，通过 AsyncResultTemplate 使用同步/异步等待；AsyncResultProvider 是单后端 SPI。

## 引入

坐标：`io.github.loadup-cloud:loadup-components-async-result-api`，版本由 LoadUp BOM 管理。
